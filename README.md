# Симулятор АЕС

Інтерактивний 3D-симулятор енергоблока атомної електростанції з реактором водо-водяного типу. Побудований на three.js та Vite. Оператор керує реактором, насосами, турбіною та градирнею, а система захисту, сигналізація й аварійні сценарії відтворюють поведінку блока в нештатних ситуаціях.

## Можливості

- Динамічна модель блока: реактор, первинний контур, турбіна, енергосистема, градирня.
- Панель керування з чотирма вкладками: реактор, охолодження, турбіна й мережа, аварії.
- Стрілочні прилади з кольоровими зонами, смуги стану, журнал подій і тривог з підтвердженням.
- Автоматичний захист реактора та захист турбіни.
- Тринадцять аварійних сценаріїв, які можна запускати вручну або випадково.
- 3D-сцена: корпус реактора з розрізом, турбінний зал, градирні, труби з потоком, пара, ліс, зміна освітлення залежно від стану блока.
- Аварійні ефекти: витік пари, дим із турбінного залу, блекаут, руйнування контайнменту при плавленні зони.
- Звукова сигналізація та підказка для нового користувача.

## Технології

- [three.js](https://threejs.org/) для 3D-графіки
- [Vite](https://vitejs.dev/) для збірки та dev-сервера
- Чистий JavaScript (ES-модулі), без фреймворків

## Запуск

Потрібен Node.js 18 або новіший.

```bash
npm install
npm run dev
```

Dev-сервер відкриє застосунок у браузері (за замовчуванням `http://localhost:5173`).

Інші команди:

```bash
npm run build     # збірка у папку dist
npm run preview   # перегляд зібраної версії
```

## Як влаштована симуляція

Фізична модель не залежить від three.js і живе в `src/simulation`. Крок симуляції фіксований (1/30 с), тому поведінка не залежить від частоти кадрів, а прискорення часу лише збільшує кількість кроків за кадр.

Порядок оновлення на кожному кроці: сценарії аварій, охолодження, реактор, турбіна, енергосистема, захист, сигналізація, стан блока.

- **Реактор:** кінетика потужності, зворотні зв'язки за температурою, ксенонове отруєння, борне регулювання, залишкове тепловиділення, стрижні керування, тиск, ушкодження палива.
- **Охолодження:** чотири головні циркуляційні насоси, рівень теплоносія, витік, система аварійного охолодження, вентилятори градирні.
- **Турбіна:** регулюючий клапан, тиск пари, скидна установка, розгін і вібрація, захисне відключення.
- **Енергосистема:** змінний попит, частота, втрата мережі, стрибки навантаження.

Модулі обмінюються подіями через просту шину (`src/utils/events.js`), тому симуляція, сцена й інтерфейс не залежать один від одного.

### Захист

Реактор аварійно зупиняється із затримкою 1,5 с при високій температурі теплоносія, високому тиску, низькому рівні теплоносія, високій температурі палива, втраті циркуляції, перевищенні потужності та відключенні турбіни. Автоматичний захист можна вимкнути вручну, щоб довести станцію до тяжкої аварії.

Турбіна відключається при перевищенні обертів, високій вібрації та низькому тиску пари.

### Аварійні сценарії

Відмова циркуляційного насоса, відмова групи насосів, витік теплоносія, велика теча першого контуру, відмова системи аварійного охолодження, заклинювання стрижнів, мимовільне витягування стрижнів, втрата зовнішньої мережі, стрибок споживання, збій регулятора турбіни, знос підшипників турбіни, відмова скидної установки, деградація градирні.

- `core`: рендерер, камера, головний цикл, керування ресурсами.

- `utils`: математика, форматування, шина подій, робота з DOM і сховищем.

## Обмеження

Проєкт навчальний. Номінальні параметри (3000 МВт теплових, 1000 МВт електричних, тиск 15,7 МПа) близькі до блока типу ВВЕР-1000, але динаміка процесів спрощена й не відкалібрована за даними реальної станції. Розміри будівель, візуальні ефекти аварій і звуки підібрані для наочності й не відтворюють реальні пропорції та перебіг аварій. Симулятор не призначений для навчання персоналу чи оцінки безпеки.
